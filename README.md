# 军团冲锋 Army Rush

[在线游玩](https://rem021.github.io/army-rush/)

仿 [Real War: Not Fake](https://apps.apple.com/us/app/real-war-not-fake/id6753818799) 和 Last War 广告玩法的 3D 射击小游戏。网页版，手机竖屏优先，电脑也能玩。

人物、丧尸、Boss 和道具用的是 Quaternius 的 **CC0（公共领域）** 模型，可以免费商用，来源和许可见 [public/models/CREDITS.md](public/models/CREDITS.md)；其余（门、桥、特效、界面图标、音效）由代码生成。模型文件缺失时会自动退回代码生成的小人。

## 玩法

两条主线：

**防线（默认）**：队伍守在桥头不动，只能左右换道。桥被中间的水泥墩隔成两条道：

- **门道**（左或右）：东西排成一队——**开局第一个就是大障碍**（武器轮胎、装甲路障、补给箱），打掉以后冲过来几扇数字门，再一个障碍，循环；前面每个障碍约是上一个的 3.7 倍，后面逐渐降到约 2.5 倍。大障碍滑到半路就**卡住**，后面的门挤在它身后；打爆它（升枪、加人、空袭或射速），后面那串门**一下子冲到你身上**，接着下一个障碍又卡住。
- **金币**：战斗里顶栏的金币就是能拿到的（击杀 + Boss 赏金），赢了另加通关奖励，输了保留已经拿到的。
- **钻石**：稀有货币，只用来升兵力。最终 Boss 每只给 1 颗，Boss 关通关再给 1 颗；中途 Boss 有 25% 概率给 1 颗，巨尸、胖尸、自爆尸有更低概率掉，普通丧尸不掉。每 5 关一个 **Boss 关**（双 Boss、更难，赏金和通关奖励翻倍），后面跟一个放松关。
- **尸潮道**：开局约 2.5 个游戏秒开始刷丧尸，每只头上有血条；隔一阵来一大波，中途 **Boss 一批一批从天而降**（进度条上的骷髅标出每批的位置），夹着巨尸，最后是最终 Boss（每 5 关双 Boss）。冲到桥头的丧尸会横穿过来咬你。

站在门道就只能打门和障碍，站在尸潮道就只能清丧尸——什么时候换道就是全部的取舍。

**局外升级**：升级只在战斗外做（主页底部和结算弹窗里的五张卡片，底部导航“军械库”看进化路线）。**首关可在零升级下靠操作通过**；关卡敌血固定，升级后不会跟着加血。失败保留战利品，并按推进进度给少量补给。设置里有“重置全部进度”，连续点两次确认后会清空关卡、金币、钻石、升级、皮肤和战绩，保留音效、振动、灵敏度与动态效果偏好。

| 升级 | 每级 | 进化 |
|---|---|---|
| 兵力（**用钻石买**） | 开局 1 人，每级 +2 人 | 3 / 6 / 10 / 15 / 20 级数字门各 +10% |
| 火力 | 伤害 +12% | 6 / 13 / 21 / 30 级换开局枪：冲锋枪 → 突击步枪 → 战术步枪 → 加特林 |
| 射速 | 射速 +8% | 8 / 16 / 25 级换子弹：穿甲弹（打穿一只）→ 爆裂弹（溅射）→ 电磁弹（打穿两只、大溅射） |
| 金币 | 金币 +8%（最多 12 级） | — |
| 机动 | 左右挪动 +10% | 5 / 10 级投弹预警变长（更好躲） |

**冲锋**：队伍沿大桥一路往前，左右是数字门、中间冲来尸潮；有隔离墙“选择道路”、陷阱、巨尸，终点打 Boss。人数最多 60，阵型横向保持在可闪避的宽度内；防线最多 64 人。

**免费战术**：主页或结算点“战术”，下一局生效。均衡保持标准属性；连射提高射门频率但降低单发伤害；破甲射得慢，对障碍、巨尸和 Boss 更有效。具体取舍在面板里写明。

**旧关演练**：模式页选择已通关关卡，用当前升级和战术练习；不发资源、不改主线进度和战绩。正常战斗结算会显示主要损兵来源、最后损兵原因、应对建议和接门／拆补给／闪避统计。暂停后可保留战利品重试或撤退；主动退出没有推进补给。

共同的规则：

- 子弹直线往前飞，**站在哪条道就打哪条道**。
- 门：绿门加人、红门扣人、蓝门按标出的倍数加人（常见 ×1.25 / ×1.5）、橙色武器门（打得越多枪越好）、青色射速门。朝门开枪能把数字打高，红门也能打成绿门。
- 丧尸：普通丧尸、疾行尸（快）、胖尸（一下带走 4 人）、自爆尸（撞上会炸，被打死也会炸到旁边的丧尸）、巨尸（挡路碾人，打死掉武器或空袭）。
- Boss：巨尸王（两次慢砸后接三次快砸）、投弹屠夫（扔油桶，**红圈里的兵全部炸死**）、尸巢母体（不停孵疾行尸，打死它小怪全灭）。贴脸攻击会先锁定红色危险带；左右拖动整队移出危险带就能躲开。子弹直着飞，想打 Boss 就站到它那条道上。

## 模式

| 模式 | 解锁 | 说明 |
|---|---|---|
| 防线 | 开局 | 原地死守，一边门和重甲补给滑过来，一边尸潮和 Boss 涌过来 |
| 冲锋 | 开局 | 一路冲到底，终点有 Boss，第 5 关起双 Boss |
| 火力狂潮 | 防线或冲锋通关第 30 关 | 参考图四列阵列：+1 蓝门、红军巨人、+99 弹药、多管炮架和金色弹幕 |
| 无尽 | 第 2 关 | 一直跑，越来越难，记录最远距离 |

火力狂潮按**实际通关纪录**解锁；其余模式解锁看防线和冲锋里走得更远的那条。狂潮使用独立的固定火力，只记录最佳击杀，不发放主线资源。管理员试玩打开开发版 `?admin=carnage&mode=carnage`，通行证存于当前浏览器，可在设置中关闭；它不是账号认证或服务器管理权限。

结算的金币可以在主页底部升级火力、射速、金币、机动，钻石用于升级兵力；也可以在“皮肤”里用金币买皮肤。存档在浏览器 localStorage。

操作：主页点“开始战斗”；游戏里手指或鼠标按住左右拖，键盘用 ←/→ 或 A/D，Esc 暂停。失焦或切后台会暂停，继续前留有约 0.9 秒准备时间。设置可调拖动灵敏度和动态效果。

## 运行

```bash
npm install
npm run dev        # 本机 http://localhost:5173，手机连同一 Wi-Fi 打开终端里的 Network 地址
npm run build      # 输出 dist/，纯静态，可以放到任何静态托管
```

iPhone 上用 Safari 打开后“添加到主屏幕”，就能全屏玩。iOS Safari 不支持 `navigator.vibrate`，振动只在安卓上有效。

## 发布

`main` 分支更新后，GitHub Actions 会运行测试、构建并发布 `dist/` 到 GitHub Pages。发布构建设置 `GITHUB_PAGES=true`，将 Vite 的资源根路径设为 `/army-rush/`；本机开发仍使用相对路径。

调试参数（加在网址后面）：

| 参数 | 作用 |
|---|---|
| `?mode=campaign` | 指定模式：defense / campaign / endless |
| `?level=8` | 防线或冲锋直接进第 8 关 |
| `?up=3` | 五项升级都设为 3 级 |
| `?autoplay` | 自动驾驶 |
| `?speed=3` | 3 倍速 |
| `?coins=5000` | 设置金币 |
| `?gems=20` | 设置钻石 |

## 脚本

```bash
npm test                     # 规则单测（门、墙、陷阱、各种丧尸、Boss、防线、各模式）
npm run sim                  # 平衡模拟：自动驾驶跑冲锋 1–12 关
npm run sim -- defense 12 6  # 也可以跑 campaign / endless
npm run sim:progress         # 成长模拟：从零升级开始打防线，输了买升级再打，看每关要打几次
npm run smoke:experience     # 演练隔离、结算、存档、输入与三种小屏布局回归
npm run smoke                # 冒烟测试：先 npm run dev，再用本机 Chrome 截图到 work/shots
npx tsx scripts/assets.ts    # 重新处理模型：原始素材按 CREDITS.md 下载到 work/assets-raw/，输出 public/models/*.glb
```

## 目录

```
src/game/      纯逻辑，不依赖 three.js，Node 里也能跑
  config.ts    数值：赛道、丧尸、Boss、武器、模式、皮肤、升级
  level.ts     关卡生成：冲锋的段落模板、防线的刷新表、各模式入口、难度曲线 TUNING / DEFENSE_TUNING
  world.ts     模拟：阵型、射击、门、墙、陷阱、丧尸、Boss、投弹、空袭、大巴、防线队列和尸潮，产出事件
  economy.ts   结算金币、推进补给、真实边际收益推荐和模拟购买策略
  feedback.ts  本局损兵统计和针对性建议（不上传）
  tactics.ts   免费战术及其属性取舍
  bot.ts       自动驾驶，给模拟、测试和 ?autoplay 用
src/render/    three.js 渲染：场景、特效、文字
  assets.ts    加载 public/models/ 里的 glb（meshopt 压缩）
  vat.ts       顶点动画贴图：把骨骼动画烘成浮点贴图，几百个士兵/丧尸一次绘制
  characters.ts 士兵（7 把枪）、各种丧尸、Boss（骨骼动画）、道具的外部模型
public/models/ 处理好的模型和 CREDITS.md
src/ui/        DOM 界面、样式和图标（深色战术面板 + 金色按钮，升级卡片、导航和弹层）
src/audio.ts   WebAudio 合成音效
src/main.ts    模式控制、输入、主循环、存档
scripts/       平衡模拟和冒烟测试
tests/         vitest 单测
docs/          设计说明
```
